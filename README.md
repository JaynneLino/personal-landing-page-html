# Personal Landing Page - Career Transition Journey 🚀

This is my first personal landing page, developed during the early stages of my transition from **Agronomy (MSc)** to **Data Analysis & Development**. 

The project served as a practical laboratory to master the fundamentals of web structure, styling, and responsive design.

### 🛠️ Technologies Used
- **HTML5:** Semantic structure and content.
- **CSS3:** Custom styling, Flexbox, and CSS Components architecture.
- **JavaScript:** Implementation of interactive elements like the "Back to Top" button and carousels.
- **Google Fonts:** Integration of custom typography (Fira Code & Press Start 2P).

---

### 💡 Key Features
- **Responsive Navigation:** Smooth scrolling to sections (Skills, Projects, About, Contact).
- **Interactive Carousel:** A visual timeline of my professional background (from 2012 to present).
- **Skills Section:** Visual representation of technical learning progress.
- **Contact Form:** Functional layout for user inquiries.

---

### 👩‍🔬 About the Project
This landing page reflects my journey. It highlights my academic background in **Agricultural Engineering** and my shift towards the tech industry in **Portugal**. It was built using a component-based CSS approach to ensure clean and maintainable code.
